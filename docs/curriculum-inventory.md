# מיפוי תכנית הלימודים הקיימת

מסמך עבודה לבחינת איחוד עתידי. המיפוי משקף את הקבצים והקישורים הקיימים; הוא אינו משנה תוכן, שמות, סדר או שיוך שיעורים. כותרות התכנית והמאמרים מוצגות כפי שהן במקורות, גם כאשר אינן תואמות זו לזו.
