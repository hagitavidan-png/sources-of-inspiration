# ארכיון: קבצים שהוצאו מהאתר

הקבצים כאן הוצאו מהאתר החי (ענף `gh-pages`) ב־28.9.2026, כחלק מסידור האתר. הם לא נמחקו. כל קובץ שמור בתוך התיקייה `archive/`, באותו נתיב שבו היה באתר.

כדי להחזיר קובץ לאתר, מעתיקים אותו מכאן לאותו נתיב בענף `gh-pages`.

## קבצים מפרויקטים אחרים

- `download.html`: "הורדת קבצי 7 Diamonds לגיטהאב".
- `offline-download.html`: "CreativeEdu: הורד את כל הקבצים". קישר ל־14 דפים שלא קיימים באתר.
- `lessons/lesson-template.html`: תבנית שיעור עם הכותרת "7 Diamonds | שיעור".

## קבצים שאף דף באתר לא השתמש בהם

- `public/lesson.html`, `public/css/lesson-responsive.css`: עותק ישן של השיעור לדוגמה, עם תמונות שבורות.
- `static/style.css`, `css/course.css`, `css/lesson-shared.css`, `js/lesson.js`, `js/build-units.js`.
- `data/unit-0.js` עד `data/unit-6.js`: נטענו רק על ידי `download.html`.
- שבע תמונות יצירה מ־`lessons/images/` שלא הופיעו באף שיעור: קנדינסקי (2), מאטיס, מונה (חבצלות המים), פיקאסו, רות׳קו (כתום־צהוב), ון גוך. אם שיעור עתידי יצטרך אחת מהן, אפשר להחזיר אותה.
