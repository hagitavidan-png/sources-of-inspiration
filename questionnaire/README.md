# שאלון למצפוני קבוצות בתל אביב-יפו

שלוש דרכים להפוך את השאלון לטופס דיגיטלי. בכולן בסוף המילוי מופיעים קישור לקבוצת הוואטסאפ וקישור לעלון ההסבר.

---

## אפשרות מומלצת: דף סקר בעיצוב העלון (Google Apps Script)

בתיקייה `web-app/` נמצאת גרסה שמעוצבת כמו עלון ההסבר: כרטיס לבן עם פס טורקיז, כותרות בכחול, מסגרות ציטוט, עמוד פתיחה ועמוד תודה בכחול כהה עם פס זהב, וכפתורי "הבא / הקודם" עם מונה עמודים. התשובות נשמרות בגיליון Google Sheets.

1. היכנסו ל-<https://script.google.com> ולחצו **פרויקט חדש**.
2. במקום התוכן של `Code.gs` הדביקו את `web-app/Code.gs`.
3. לחצו על **+** ליד "קבצים", בחרו **HTML**, קראו לקובץ `Index` והדביקו את `web-app/Index.html`.
4. בחרו בפונקציה `setup` ולחצו **הפעלה** (Run). אשרו הרשאות. ביומן יופיע קישור לגיליון התשובות.
5. **פריסה** (Deploy) ← **פריסה חדשה** ← סוג: **אפליקציית אינטרנט** (Web app).
   הפעלה בתור: **אני**. מי יכול לגשת: **כל אחד** (Anyone).
6. הקישור שמתקבל (מסתיים ב-`/exec`) הוא הקישור לשליחה למצפונים.

אחרי שינוי בקבצים צריך לבצע **פריסה** ← **ניהול פריסות** ← עריכה ← **גרסה חדשה**, כדי שהקישור הקיים יתעדכן.

## אירוח באתר הארגון (na-tel-aviv.github.io)

כך כתובת הסקר תהיה `https://na-tel-aviv.github.io/survey.html`, בלי שם אישי. התשובות עדיין נשמרות בגיליון Google.

1. בצעו את שלבים 1–5 של האפשרות המומלצת למעלה, רצוי מחשבון Gmail של השירות ולא מחשבון אישי. העתיקו את קישור ה-`/exec`.
2. בקובץ `github-pages-survey.html` החליפו את `REPLACE_WITH_APPS_SCRIPT_EXEC_URL` בקישור ה-`/exec`.
3. העלו את הקובץ למאגר `na-tel-aviv/na-tel-aviv.github.io` בשם `survey.html` (ב-GitHub: **Add file** ← **Upload files**).
4. בדף הבית כדאי להוסיף כפתור "שאלון למצפוני קבוצות" שמקשר ל-`survey.html`.

## אפשרות א': Google Forms (אוטומטי, כ-2 דקות)

הסקריפט `create-google-form.gs` בונה את כל הטופס בלחיצה אחת, כולל הדילוג המותנה וגיליון תשובות.

1. היכנסו ל-<https://script.google.com> ולחצו **פרויקט חדש**.
2. מחקו את התוכן בעורך והדביקו את כל התוכן של `create-google-form.gs`.
3. (הקישור לקבוצת הוואטסאפ כבר מוגדר בשורה `WHATSAPP_LINK`; אפשר לשנות אותו שם אם צריך.)
4. בחרו בפונקציה `createForm` ולחצו **הפעלה** (Run). בפעם הראשונה Google תבקש לאשר הרשאות.
5. ב**יומן הביצוע** (Execution log) יופיעו שלושה קישורים:
   - קישור למילוי: אותו שולחים למצפונים.
   - קישור לעריכת הטופס.
   - גיליון Google Sheets שאליו נכנסות כל התשובות.

## אפשרות ב': Tally (ידני, כ-15 דקות)

ב-Tally אין ייבוא אוטומטי, אבל הבנייה פשוטה: מקלידים `/` כדי להוסיף שאלה.

1. היכנסו ל-<https://tally.so> ולחצו **Create form**.
2. בכותרת הטופס הדביקו: **שאלון למצפוני קבוצות בתל אביב-יפו**, ומתחתיה את טקסט הפתיחה (סעיף "טקסט פתיחה" למטה).
3. הוסיפו את השאלות לפי הטבלה. כדי לסמן שאלה כחובה, לחצו על הכוכבית ליד כותרת השאלה.
4. **דילוג מותנה:** אחרי שאלה 5 (שליח/ה) הוסיפו `/Page break`, ובעמוד החדש שימו את שאלה 6 (קשיים).
   מעל שאלה 6 הוסיפו `/Conditional logic`:
   *When* "האם לקבוצה יש כיום שליח/ה..." *is* "כן, באופן קבוע" → *Jump to page* 3 (או *Hide block* על שאלה 6).
5. **עמוד תודה:** בסוף הטופס הקלידו `/Thank you page` והדביקו את טקסט הסיום (כולל הקישורים). ב-Tally קישורים בעמוד התודה לחיצים.
6. יישור לימין: אם הטקסט מוצג משמאל, פתחו **Settings** וחפשו את אפשרות הכיווון **Right-to-left**.
7. לחצו **Publish** והעתיקו את הקישור.
8. התשובות נמצאות בלשונית **Submissions**; אפשר לחבר ל-Google Sheets דרך **Integrations**.

## תיקונים שנעשו בנוסח המקורי

- נמחקה אפשרות ריקה (D) בשאלת השליח/ה, וכן "וק" שנשאר אחרי הקישור לוואטסאפ.
- שאלת הקשיים מוצגת גם למי שענה "אין כרגע שליח/ה", כי אחת האפשרויות בה היא "אין כרגע משרת/ת לתפקיד".
- "סיבה אחרת" ו"אחר" הפכו לאפשרות Other עם שדה טקסט.
- "ועדת" אוחד לכתיב "וועדת" בכל השאלון.
